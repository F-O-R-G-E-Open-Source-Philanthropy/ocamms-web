> **The Story Behind the Name**<br>
> The name is an ironic nod to **Occam's Razor**, the philosophical principle stating that the simplest solution is usually the best. In software engineering, we constantly strive for simplicity, yet we inevitably weave intricate, tangled webs of architectural dependencies. Occam's Web embraces this paradox by untangling that complexity, visualizing the dependencies with neon path from your UI components all the way down to your database layers so that the underlying simplicity can be found.

## 🚀 Core Features (Current)

| Feature | Description |
| :--- | :--- |
| 🧩 **Real-time Parsing Engine** | Native drag-and-drop support for both files and nested directories. Extracts variables, functions, and import paths automatically. |
| 🗄️ **Intelligent DB Detection** | Specifically hunts for `IndexedDB` and `localStorage` instances, generating unique pure-icon nodes to visualize database bottlenecks. |
| 📦 **Dynamic AABB Hierarchies** | Generates ghostly, glowing bounding boxes around files based on their physical folder structure, resizing dynamically as you reorganize the canvas. |
| 💾 **IndexedDB Sessions** | Save, load, and manage multiple complex architectural pipelines without relying on external databases or cloud storage. |
| 🎨 **Glassmorphic UI** | A premium midnight-blue to black-russian gradient featuring dynamic glowing data packets traversing Bezier-curved dependency edges. |

## 🗺️ Upcoming Roadmap

We are currently planning the implementation of four major architectural upgrades to transform this visualizer into an indispensable diagnostic engine:

<details>
<summary><b>1. Directed Edges & Cyclic Dependency Alerts</b></summary>
<br>
Visualizing a graph is pretty, but highlighting architectural flaws is valuable. We will be implementing directional data flow animations and an algorithm to detect circular dependencies (e.g., A → B → C → A). These structural risks will be highlighted in a pulsing red warning color to catch build-time errors before they happen.
</details>

<details>
<summary><b>2. Focus Mode (Search & Isolate)</b></summary>
<br>
In massive projects, dependency graphs quickly become unreadable "hairballs." We will introduce a search feature that activates *Focus Mode*, dimming the entire matrix except for the searched node and its direct ancestors/descendants, allowing you to instantly isolate the blast radius of a single script.
</details>

<details>
<summary><b>3. "God Object" Metric Overlays</b></summary>
<br>
Nodes will automatically scale their size, glow intensity, and border thickness based on their total number of inbound connections. This will allow teams to instantly identify bottleneck scripts or "God objects" where a single file change risks breaking the entire application.
</details>

<details>
<summary><b>4. Matrix Exporting (JSON & CI/CD Ready)</b></summary>
<br>
Occam's Web will soon support exporting not just visual screenshots, but a structured JSON mapping of the parsed dependencies. Developers can feed this JSON directly into documentation generators or CI/CD pipelines to enforce architectural rules automatically.
</details>
